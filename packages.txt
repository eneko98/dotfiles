# Packages this desktop adds, in the order they were added.
#
# A fresh Arch install only provides the baseline: base, base-devel, linux,
# linux-firmware, amd-ucode, mesa, git, neovim, pipewire, sudo. Everything
# listed below is what sits on top of that, one section per component.
#
# Install everything with:
#   grep -vE '^\s*(#|$)' packages.txt | sudo pacman -S --needed -
#
# The comment/blank-line filtering is needed because pacman treats every line
# it reads from stdin as a package name, comments included.

# 01 - graphics stack and fonts
# vulkan-radeon is *not* required by Hyprland (aquamarine only needs mesa/EGL),
# but it is the recommended driver for AMD on Wayland and any future Vulkan
# application needs it, so it is installed up front.
vulkan-radeon
vulkan-icd-loader
fontconfig
ttf-jetbrains-mono-nerd

# 01 - fallback kernel
# Insurance: systemd-boot gets a second, known-good entry to boot from if a
# graphics or kernel change breaks the main one. This package alone is NOT
# enough -- systemd-boot here reads only Type #1 entries, so
# /boot/loader/entries/arch-linux-lts.conf had to be written by hand too.
linux-lts

# 02 - compositor and terminal
hyprland
kitty

# 02 - cursor theme
# The fallback that /usr/share/icons/default inherits: a bare install had no
# cursor theme at all. The pointer itself is Bibata Modern Ice, an AUR package
# listed in the note at the end of this file.
adwaita-cursors

# 03 - zsh and oh-my-zsh
# oh-my-zsh itself is not a package; it is cloned into XDG_DATA_HOME. See the
# README, which also covers the /etc/zsh/zshenv line that makes ZDOTDIR work.
# Only the archlinux plugin ships with oh-my-zsh; the other three come from the
# repos and are sourced by hand from config/zsh/.zshrc.
zsh
zsh-autosuggestions
zsh-syntax-highlighting
zsh-completions

# 04 - session manager
# uwsm wraps the compositor in systemd user units -- wayland-wm@hyprland.desktop.service
# pulled in by graphical-session.target -- instead of leaving it as a bare process, and
# gives SUPER+M a clean "uwsm stop" path out. Started by config/zsh/.zprofile; the tty1
# autologin drop-in around it is in the README.
uwsm

# 05 - wallpaper
# hyprpaper paints the wall behind the windows. Chosen over swaybg because it has
# IPC -- `hyprctl hyprpaper wallpaper ...` changes it live -- and over swww/mpvpaper
# because those are AUR-only and there is no AUR helper yet.
# It is started by the systemd user unit the package ships, not from hyprland.lua:
# the uwsm wiki recommends the unit, and a unit restarts on crash and stops with the
# session. One-time setup: systemctl --user enable hyprpaper.service
hyprpaper

# 08 - desktop essentials: the application launcher
# fuzzel, on SUPER + Space. Toolkit-free -- no GTK, no X11, unlike wofi (GTK) or
# dmenu (X11, needs XWayland). Its colours are generated from the palette by
# scripts/gen-theme.py, which is the fourth consumer and the reason that script
# exists at all.
fuzzel

# 08 - desktop essentials: screenshots
# grim reads pixels from the compositor and writes a PNG, slurp is the "drag a
# rectangle" part, wl-clipboard puts the result on the clipboard so a shot can be
# pasted straight into a chat. All three in extra: no portal, no daemon, 185 KiB
# together. Driven by config/hypr/scripts/screenshot.
grim
slurp
wl-clipboard

# 08 - desktop essentials: lock screen and idle
# hyprlock draws the lock screen, hypridle decides when: lock after 5 minutes,
# screen off after 10, suspend after 30, and lock before any sleep (which is what
# a lid close triggers, logind's HandleLidSwitch default being suspend). hyprlock
# is hyprlang, so its palette is generated by scripts/gen-theme.py as hyprlang
# variables and sourced by config/hypr/hyprlock.conf. hypridle runs as the unit
# the package ships:
#     systemctl --user enable --now hypridle.service
hyprlock
hypridle

# 08 - desktop essentials: volume, brightness and media keys
# wpctl is already here with wireplumber, so the volume keys need no new package;
# pavucontrol is the GUI mixer (and a way to pick the default sink/source).
# brightnessctl writes the backlight through the permissions udev/logind already
# grant the active user, so no sudo or extra group is needed. playerctl drives
# whichever MPRIS player is running, so the media keys work with mpv, Firefox
# and the like without knowing which one is playing.
brightnessctl
pavucontrol
playerctl

# 08 - desktop essentials: notifications
# mako is a Wayland-native notification daemon with no toolkit: its dependencies
# (cairo, gdk-pixbuf, glib, pango, wayland) were all already installed. Its
# colours are generated from the palette, so it is one more copy of theme.lua.
# libnotify is only here for notify-send, which is how one tests a notification
# daemon and what scripts tend to use. mako ships no systemd unit, so this repo
# carries one. The Quickshell notification centre now owns
# org.freedesktop.Notifications, so mako is stopped and disabled; the package,
# theme and unit stay as a fallback:
#     systemctl --user disable --now mako.service
mako
libnotify

# 08 - desktop essentials: portals and the polkit agent
# The portal is how sandboxes and modern apps ask the desktop for things: file
# pickers, screen sharing, screenshots. xdg-desktop-portal reads one backend per
# interface, chosen by UseIn -- the GTK backend does FileChooser and friends, the
# Hyprland backend does Screenshot/ScreenCast/GlobalShortcuts. Both are needed.
# The agent is what actually draws a password prompt; polkitd (the daemon) was
# already installed but could not ask anyone anything without one.
# polkit-gnome rather than hyprpolkitagent: 64 KiB and no new dependencies, where
# the Hyprland one drags in Qt6 plus declarative (~55 MiB). It ships no unit, so
# this repo carries one:
#     systemctl --user enable --now polkit-gnome.service
xdg-desktop-portal
xdg-desktop-portal-gtk
xdg-desktop-portal-hyprland
polkit-gnome

# 08 - desktop essentials: clipboard history
# cliphist keeps what you copied, so the second copy no longer destroys the
# first. `wl-paste --watch cliphist store` does the collecting and is a unit the
# package does not ship, so this repo carries one. The picker is fuzzel in dmenu
# mode, on SUPER + V.
cliphist

# 08 - desktop essentials: the home directories
# So ~/Documents, ~/Downloads and friends exist and every program agrees on
# where they are. One command, run once (see the README); the file it generates,
# ~/.config/user-dirs.dirs, is not tracked on purpose -- xdg-user-dirs rewrites
# it in place, which through a symlink would write into the repo.
xdg-user-dirs

# CJK and emoji fonts
# Until now every Chinese character was a tofu box. Source Han Sans CN rather
# than noto-fonts-cjk: 56 MiB against 299 MiB, because Noto ships all four
# regional families where this one font already answers for zh-cn, zh-tw, ja and
# ko (checked with `fc-match` per language, and with a Traditional-only glyph and
# a kana). Glyph *forms* are the Simplified ones; add the TW/HK variant later if
# the Traditional shapes matter. Noto Color Emoji covers the emoji.
# The bar and the lock use Adwaita Sans now (the CJK serif left with the old
# identity), so the sans is only needed for actual Chinese text.
adobe-source-han-sans-cn-fonts
noto-fonts-emoji

# 09 - file manager
# yazi is the file manager, with image, video, PDF and archive previews inside
# the terminal. fd, ripgrep, fzf and zoxide are the surrounding tools: fast find,
# fast grep, fuzzy selection and learned cd. The yazi theme is generated from the
# palette, so scripts/gen-theme.py gains a fifth consumer. xdg-utils is needed
# for the default "open with" behaviour.
yazi
fd
ripgrep
fzf
zoxide
jq
ffmpegthumbnailer
poppler
imagemagick
7zip
chafa
xdg-utils

# terminal niceties
# lsd replaces ls with colours and Nerd Font icons; bat replaces cat with
# syntax highlighting. Both are aliased in config/zsh/aliases.zsh, so `ls` and
# `cat` keep working but look better. bat is themed with `ansi`, so it borrows
# the terminal's 16 colours instead of shipping a palette of its own.
lsd
bat

# theme pass: Qt theming
# qt6ct is how Qt apps read the palette and the icon theme. The cursor
# (Bibata-Modern-Ice) and the Adwaita-* icon variants are AUR-only, so they are
# listed in the note below rather than here; gen-theme.py picks the variant.
qt6ct

# Phase 3 - our own bar
# Quickshell draws the bar. It is a Qt6/QML toolkit for Wayland shells: the
# visuals are QML (QtQuick), and it ships modules for the things a bar needs
# (Hyprland workspaces, the system clock, MPRIS, the system tray, ...). Started
# by the unit this repo carries:
#     systemctl --user enable --now quickshell.service
quickshell

# Bluetooth
# The adapter was already present (hci0) but soft-blocked, and BlueZ was not
# installed, so nothing could talk to it. bluez is the daemon, bluez-utils
# brings bluetoothctl. Enabled as a system service and the block cleared:
#     sudo systemctl enable --now bluetooth.service
#     sudo rfkill unblock bluetooth
bluez
bluez-utils

# Bluetooth pairing agent: bluez-tools brings bt-agent, which registers a BlueZ
# agent with the NoInputNoOutput capability. The bar's bluetooth popup starts it
# only while the popup is open, so pairing is possible exactly when the user is
# looking at the popup. Without it, pair() fails: bluez alone has no agent.
bluez-tools

# Battery
# upower exposes the battery over D-Bus. Its daemon is D-Bus activated, so the
# package is enough: no service to enable. The bar reads UPower.displayDevice.
upower

# Night light
# hyprsunset applies a blue-light filter through the compositor (a CTM matrix,
# not a screen shader), so it does not show up in screenshots. Its package ships
# the systemd user unit; the control centre toggles it over IPC.
hyprsunset

# Weather
# The control centre asks wttr.in for the current conditions: no API key, but it
# needs curl. The query runs on demand, so there is no daemon and no polling.
curl

# Browser
# Firefox, for the web (and for browsing r/unixporn while deciding what to build
# next). Native Wayland through the MOZ_ENABLE_WAYLAND=1 already in the session
# environment. Its profile lives in ~/.mozilla and is machine state, not tracked.
firefox

# ---------------------------------------------------------------------------
# Everything above is in the repos and can be installed with the command at the
# top of this file. The one exception is the AUR helper, which pacman cannot
# install, so it is NOT listed here:
#
#   paru    built once from source with git + makepkg -si:
#             git clone https://aur.archlinux.org/paru.git
#             cd paru && makepkg -si
#
# paru-bin is deliberately not used: its prebuilt binary links against
# libalpm.so.15 while this system ships .16 (pacman 7.1), so it will not start.
# Building from source also means cargo/rust is installed as a make dependency
# and then removed; config/paru/paru.conf sets RemoveMake so future builds clean
# their own toolchains up.
#
# The cursor and icon themes are AUR-only too:
#   paru -S bibata-cursor-git adwaita-colors-icon-theme
#   bibata-cursor-git: Bibata Modern Classic/Ice/Amber, hyprcursor + xcursor;
#                      we use Bibata-Modern-Ice (neutral white, rounded)
#   adwaita-colors: Adwaita with the folders/places recoloured; the variant follows
#                   the accent (Adwaita-teal for the default blue palette)
# ---------------------------------------------------------------------------

# Login manager: greetd + regreet under cage
# A graphical greeter instead of the tty1 autologin. greetd owns tty1 and its
# unit conflicts with getty@tty1; cage is the kiosk compositor regreet draws in;
# gtk4-layer-shell lets regreet fill it. The greeter user comes with greetd (in
# the video group). The configs and the background copy live in the README.
greetd
greetd-regreet
cage
gtk4-layer-shell
